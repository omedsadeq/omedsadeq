BioZheen Static Site

Overview

Static website built with Bootstrap 4 and custom CSS. Open `index.html` directly in a browser.

Documentation

- Docs index: `docs/INDEX.md`
- Pages reference: `docs/pages.md`
- Components: `docs/components.md`
- Styles: `docs/styles.md`
- Scripts: `docs/scripts.md`

Local Usage

1) Open any HTML file in your browser
2) Ensure the `css/` and `img/` folders match paths used in HTML
3) For Google Maps on `contact.html`, set a valid API key

Structure

- HTML pages: root directory
- CSS: `css/style.css` (linked by pages)
- Images: `img/`
- Docs: `docs/`
