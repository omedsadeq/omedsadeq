Pages Reference

index.html (Home)

- Header/contact bar (`header.bg-primary`)
- Navbar (`.navbar` with brand image `img/logo2.png`)
- Two-column hero with images (`.middle` containers)
- Features list in bottom section (`.bottom ul`)
- Appointment form with fields: first name, last name, email, mobile, sex, date, message
- Footer (`footer.bg-dark`)

about.html (About Us)

- Same header and navbar
- Left column: About content with headings and paragraphs
- Right column: Images (`img/r1.jpg`, `img/kl.jpg`)
- Footer

service.html (Services)

- Same header and navbar
- Services list and departments list
- Right column image (`img/serv.jpg`)
- Appointment form (same fields as on Home)
- Footer

doctor.html (Doctors)

- Same header and navbar
- Doctor profiles rendered with `.doctor-profile`, `.doctor-photo`, `.doctor-info`
- Four example doctors and placeholders for affiliations and education
- Appointment form
- Footer

contact.html (Contact)

- Same header and navbar
- Contact form with fields: name, email, phone, alternate email, subject, message
- Google Map container `#map-container` and `initMap` function
- Right column images (`img/bio.jpg`, `img/cov.png`)
- Footer

Navigation Active State

- Each page sets its current nav item to `li.nav-item.active`
